# Compound Box - 五款参考作品的地图与机制拆解

参考作品：

- Patrick's Parabox
- Recursed
- Sokobond
- Snakebird
- Can of Wormholes

目标不是复制关卡，而是提取它们的规则组织方式、地图语法、教学顺序和反馈原则，再转化为适合《Compound Box》的原创机制。

## 1. 总览

| 作品 | 主要学习方向 | 对《Compound Box》的价值 |
| --- | --- | --- |
| Patrick's Parabox | 空间包含和整体传送 | 复合体传送预览、作用域清晰 |
| Recursed | 世界结构本身可被操作 | 可移动传送器、拓扑变化 |
| Sokobond | 部件连接成更高层实体 | 多材质复合体、键合目标 |
| Snakebird | 多格身体和顺序约束 | 有序链体、连接点、定向切分 |
| Can of Wormholes | 同一个物体的多种变换 | 旋转、切片、翻转、压缩 |

这五款作品共同证明：

1. 解谜深度可以来自少数规则的组合，而不是大量功能。
2. 地图本身是教学工具，不需要依赖教程弹窗。
3. 多格物体的轮廓和连接关系必须始终保持可读。
4. 一个动作如果同时改变多个空间关系，就能产生高级谜题。
5. 新规则必须先在安全房间中单独出现，再参与综合谜题。

## 2. Patrick's Parabox

### 核心机制

- 盒子可以包含空间或更小的盒子
- 进入和离开空间是核心动作
- 物体、空间和关卡边界具有层级关系
- 玩家必须同时理解“我所在的层级”和“物体所在的层级”

### 地图语法

- 每个空间有明显边界，边界不是纯装饰
- 入口和出口使用稳定、重复的视觉语言
- 玩家看到的房间就是当前作用域，避免无意义的远景干扰
- 复杂谜题来自多个空间关系叠加，而不是地图面积扩大

### 教学节奏

1. 只展示一个盒子与一个普通房间
2. 让玩家理解进入盒子和离开盒子的方向
3. 引入可以推动的盒子
4. 引入盒子内部的物体影响外部空间
5. 最后才组合多个层级关系

### 可迁移到《Compound Box》

- 传送门入口和出口必须形成一个封闭的视觉语法
- 多格物体进入传送门时显示完整的“即将出现的位置预览”
- 传送动画应该搬移整体轮廓，而不是逐格闪动
- 每个传送门关卡只新增一个空间变量，例如方向、距离或物体大小

### 不建议直接照搬

不进入递归空间。递归会带来更高的数据模型、UI 和测试成本，当前 Demo 的核心差异仍然是拆分和重组。

### 具体机制落点

实现“传送预览层”：

- 玩家选择某实体后，显示它移动后的整体轮廓
- 如果会进入传送门，显示出口位置的半透明 ghost
- 如果出口位置非法，预览显示红色并提示阻挡

这会让锚点式整体传送从程序规则变成玩家可预判的空间规则。

## 3. Recursed

### 核心机制

- 房间既是地图，也是可移动对象
- 物品和空间没有绝对边界
- 移动、复制、排列房间会改变世界结构
- 玩家操作的是拓扑关系，而不只是角色位置

### 地图语法

- 房间边缘和普通墙壁具有不同语义
- 容器内部结构必须清晰可读
- 一张地图通常只允许少数几个结构性节点
- 结构改变后，旧路径可能获得完全不同的含义

### 教学节奏

- 先让玩家理解一个房间可以被视为物品
- 再让玩家移动这个物品
- 然后让物品内部与外部的状态互相影响
- 最后引入多个结构节点同时参与谜题

### 可迁移到《Compound Box》

不必使用完整递归，可以采用更轻量的“可移动拓扑节点”：

- 传送门的一端是可以被推动的实体
- 玩家可以改变传送门入口的位置，但不能改变关卡边界
- 传送门节点本身可能被复合体覆盖、阻挡或移动
- 另一个传送端保持固定，形成动态路线设计

### 具体机制落点

新增“移动传送器”：

- `PortalNodeEntity` 具有材质和格子形状
- 玩家可以像推动普通实体一样推动传送节点
- 节点位置变化后立即更新传送映射
- 节点可以通过传送门移动，但不能与另一个节点重合

这个机制能让玩家直接改变关卡结构，同时不需要实现完整嵌套空间。

## 4. Sokobond

### 核心机制

- 单个原子是基础操作单位
- 原子在特定条件下连接成分子
- 连接后的结构具有新的整体行为
- 目标不是简单到达某点，而是形成正确的组合

### 地图语法

- 地图非常稀疏，减少无关信息
- 原子、连接关系和目标结构是唯一视觉重点
- 关卡通常围绕一个组合规律展开
- 成功状态是整个结构稳定，而不是单格高亮

### 教学节奏

1. 先学习单独移动
2. 再学习两个部件如何连接
3. 然后学习连接后的整体如何移动
4. 最后学习多个连接条件同时满足

### 可迁移到《Compound Box》

这是五个作品里最需要吸收的机制。

建议把当前“单材质实体”升级为“逐格材质实体”：

- 一个复合体可以同时包含不同颜色的部件
- 每个格子保存自己的材质
- 拆分后每个部件保留自身材质
- 重组不再只要求同材质，而是依据连接端点的材质规则

### 第一批连接规则

- 同材质可以连接
- 不同材质默认不能连接
- 特殊目标可以要求“混合连接”
- 传送门可以按材质过滤

不要一开始引入完整化学价键。保留“连接条件清楚、结果稳定、容易视觉表达”三项即可。

### 具体机制落点

新增“分子目标”：

- 复合目标显示所需轮廓和每个格子的材质
- 目标要求必须是同一个复合体覆盖
- 目标满足时，连接线从“构造中”变为“稳定”

这让重组从“把两个块放一起”升级成“设计一个满足机器规格的对象”。

## 5. Snakebird

### 核心机制

- 一个角色由多个有顺序的格子组成
- 身体会互相支撑，也会形成阻碍
- 身体姿态和重力共同决定可行动路线
- 多只蛇同时存在时，还会产生空间占用顺序

### 地图语法

- 垂直空间比水平空间更重要
- 平台、悬崖和身体堆叠关系必须一眼可读
- 头、身体和尾部使用连续视觉语言
- 地图中的支撑关系比路径长度更重要

### 教学节奏

- 先学习单只蛇的移动和重力
- 再学习身体堆叠
- 然后学习多个蛇的关系
- 最后引入需要牺牲当前姿态才能完成的路径

### 可迁移到《Compound Box》

我们的逻辑是俯视二维网格，不适合直接加入重力，但可以借用“有序身体”和“连接约束”：

- 复合实体增加连接图，记录哪些格子相连
- 拆分不是简单地变成 1x1，而是沿着连接边切成两个子形状
- 重组要求连接端点匹配，而不只是两个格子碰在一起
- 可选的“链体”拥有头部和尾部，移动顺序影响形态变化

### 具体机制落点

新增“精确切割”：

- 玩家面向复合体的某条连接边
- 按切割键后只切断这条边
- 复合体分裂为两个仍然保持内部连接的组件
- 重新靠近时可以从对应端点重新连接

它比当前“全部拆成单格”更难，但更适合中后期关卡，能显著提高机制深度。

## 6. Can of Wormholes

### 核心机制

- 同一个多格物体可以被推、切、吞、翻转和压缩
- 每个动作改变的是物体状态，而不只是位置
- 较小的动作集合可以组合出大量空间结果

### 地图语法

- 地图通常紧凑，物体会成为场景中心
- 每种变换有明确视觉结果
- 环境主要提供变换所需的边界和空间
- 谜题不依赖大量装饰信息

### 教学节奏

- 一个房间只教一个新动作
- 随后让玩家把这个动作应用到旧物体
- 最后把多个变换叠加到同一物体上

### 可迁移到《Compound Box》

优先考虑两个动作：

#### 旋转

- 复合体围绕锚点旋转 90 度
- 旋转前保留完整预热轮廓
- 如果旋转后越界或重叠则禁止
- 适合让玩家改变物体通过窄道的方式

#### 翻转

- 围绕水平或垂直轴翻转形状
- 对不对称结构尤其有用
- 可与旋转共享动画和占用验证

### 不建议直接照搬

不一次加入推、切、吞、翻转、压缩五种动作。当前阶段只选择旋转和精确切割中的一种，保持输入和视觉反馈可控。

## 8. 地图语法建议

### 基础语义层

- 地板：可移动网格
- 墙：固定边界
- 目标：材质与形状要求
- 出口：关卡完成后的离开路径
- 传送门：带编号或颜色的成对节点
- 闸门：由复合体结构或压力板控制
- 压力板：要求指定数量或指定布局

### 物体语义层

- 单格实体：最简单的基础单位
- 复合体：两个以上格子保持连接
- 链体：具有顺序的连接结构
- 传送节点：可移动的规则节点
- 混合材质实体：包含多种连接材料

### 视觉关系层

- 同一复合体使用统一轮廓
- 连接边用连续线条或接缝表达
- 不同材质只改变部件颜色，不改变整体轮廓规则
- 传送门入口和出口使用同一个符号家族
- 目标使用形状轮廓和材质填充双重编码

## 10. 关卡制作模板

每个新机制应经历四种房间：

### 1. 引入房

- 只有一个新机制
- 没有时间压力
- 玩家可以在 3 到 5 个动作内完成
- 失败后立即重开

### 2. 对照房

- 两次操作看起来相似
- 但其中一个违反新规则
- 通过差异让玩家自己总结规则

### 3. 组合房

- 新机制与一个旧机制组合
- 目标仍然单一
- 答案需要一个明显的“aha”转折

### 4. 综合房

- 使用两到三个机制
- 允许存在中间状态
- 需要撤销或预判
- 完成后解锁一个新的区域或机器状态

## 11. 每一关需要记录的制作数据

- 关卡 ID
- 主要教学机制
- 允许出现的旧机制
- 标准解法
- 最短动作数
- 最少推动数
- 是否存在多解
- 常见失败状态
- 失败状态是否可以通过撤销恢复

这些数据可以进入后续编辑器和自动求解器。

## 12. 立即可执行的设计决策

### 当前 Demo 优先级

1. 保留 12 个现有递进关卡。
2. 继续完善不规则复合体的传送预览。
3. 维持逐格材质和复合连接数据。
4. 继续扩充混合材质目标关。
5. 增加材质过滤传送门关。
6. 增加更多精确切割和旋转综合关。

### 暂缓内容

- 完整递归空间
- 复制房间
- 重力模拟
- 五种身体变换
- 随机谜题
- 战斗和敌人

## 13. 最终设计判断

《Compound Box》的学习重点不是变成 Parabox、Sokobond 或 Snakebird 的拼接版，而是形成自己的规则闭环：

1. 用 Parabox 的方式表达整体传送。
2. 用 Sokobond 的方式表达多材质连接。
3. 用 Snakebird 的方式表达复合体连接结构。
4. 用 Can of Wormholes 的方式表达结构变换。
5. 用 Recursed 的方式表达可移动的规则节点。

最终玩家应该理解的一句话是：

> 我不是在推动箱子，而是在改变物质的结构，并让结构适应机器。
