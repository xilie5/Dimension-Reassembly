# Compound Box - 同类游戏与竞品调研

调研日期：2026-09-17  
样本来源：Steam 官方商店搜索、Steam AppDetails API、各游戏官方商店简介  
说明：Steam 推荐数只是公开样本之一，受发售时间、折扣、平台和评价门槛影响，不能等同于销量或质量排名。

## 1. 结论摘要

我们的核心机制，可以压缩成一句市场定位：

> 把多格物质拆开，穿过传送门，再重新拼成能够满足机器的形状。

目前市面上已有大量 Sokoban、递归空间和化学组合解谜，但较少作品同时强调：

- 物体由多个有语义的格子组成
- 玩家可以主动拆分和重组
- 传送对象保持整体形状和锚点
- 目标要求特定结构，而不仅是把箱子放到点上

最值得组合借鉴的方向是：

1. Patrick's Parabox 的空间规则可读性
2. Recursed 对世界结构本身的操纵
3. Sokobond / Sokobond Express 的分子组合主题
4. Snakebird / Can of Wormholes 的多格身体管理
5. A Monster's Expedition 的低惩罚开放推进
6. Railbound 的关卡编辑器和内容工作流

不建议把其他作品的所有优点直接叠加。我们真正的差异点应该始终围绕：

**复合结构、拆分、传送、重组、目标形状**

## 3. 重点竞品拆解

### 3.1 Patrick's Parabox

Steam 简介强调“盒子里面还有盒子”，核心不是普通传送，而是空间本身可以被递归嵌套。

可以借鉴：

- 每个房间只引入一个空间关系
- 玩家一旦理解规则，后续关卡只改变组合方式
- 视觉界面极简，所有注意力都留给空间关系
- 不会用剧情遮住规则

我们的对应设计：

- 传送门不是装饰，而是持续存在的规则
- 复合体传送后必须保持完整结构和相对形状
- 先教学单格传送，再教学多格锚点传送

不能照搬：

- 递归嵌套会增加实现复杂度和美术成本
- 当前 Demo 的卖点是拆分与重组，不是空间无限递归

### 3.2 Recursed

房间是物品，物品也是房间，玩家通过移动、复制和重新排列房间改变世界结构。

可以借鉴：

- 让“改变结构”本身成为主要玩法
- 世界结构变化和谜题状态必须完全同步
- 一个关卡可以围绕一次结构性转折设计

我们的对应设计：

- 拆分和重组就是改变结构
- 多格传送门改变的是结构在棋盘上的位置
- 未来可加入“承载实体的移动房间”或可移动传送器

### 3.3 Sokobond / Sokobond Express

Sokobond 的核心是原子通过连接形成分子。Sokobond Express 进一步把化学键和路径规划结合。

可以借鉴：

- 玩家会自然理解“不同部件组合成整体”
- 组合规则只有少量连接条件，却能产生大量结果
- 名称、视觉和目标都围绕组合建立统一主题

我们的对应设计：

- 同材质、相邻、连通是重组条件
- 复合目标是“形状要求”，比单纯数量目标更符合主题
- 后续可以增加不同材质的连接规则或键类型

需要强化：

- 目前重组的视觉反馈还可以更像“连接成机器结构”
- HUD 可以显示复合体的结构状态，而不是只显示材质

### 3.4 Snakebird

玩家控制一条多格蛇，身体会受重力影响，也会相互支撑。身体本身就是障碍、平台和操作对象。

可以借鉴：

- 多格实体必须让玩家一眼看懂头、身体和整体轮廓
- 改变身体形状会改变可行路线
- 同一身体在不同空间的姿态就是谜题

我们的对应设计：

- 每个格子都要有明显的连接关系，不能看起来像独立箱子
- 拆分时应该明确显示原来的连接被切断
- 重组时要明确显示新的整体轮廓

### 3.5 Can of Wormholes

商店简介明确提到推、切、吞、翻转和压缩。它展示了多动作身体状态的组合潜力。

可以借鉴：

- 不要只增加“更多箱子”，而要增加身体状态
- 每个新动词都应该改变已有谜题的理解方式
- 虫体和环境之间的互动比纯推箱更丰富

我们的对应设计：

- 拆分、传送、重组已经形成三个基本状态转换
- 后续最自然的新增动作是“旋转”或“交换两个部件”
- 如果要增加动词，必须让玩家能在 3 秒内看懂结果

### 3.6 A Good Snowman Is Hard To Build

目标不是单纯把球推到某处，而是把球组合成正确的雪人形状。

可以借鉴：

- 形状本身可以是目标
- 温和的画面可以降低高难度谜题的挫败感
- 目标预览应该和实际物体使用同一种视觉语言

我们的对应设计：

- 复合目标应该直接显示所需轮廓
- 目标不仅要显示材质，还要显示需要几个格子以及大致结构
- 目标满足时，形状反馈要比普通格子高亮更强

## 4. 邻近作品的系统启发

### Baba Is You

适合借鉴规则教学和涌现式组合，但不建议引入词条系统。我们的规则数量应该可控，组合来自空间和形状。

### A Monster's Expedition

值得借鉴的是低惩罚和开放探索。商业版可以有一个小型中枢或群岛式关卡地图，但每个房间仍保持独立规则。

### Bonfire Peaks

值得借鉴的是箱子的重量感和空间纵深。我们可以通过轻微阴影、落地音效和移动惯性表现物质重量，不需要真的加入物理模拟。

### Stephen's Sausage Roll

最值得借鉴的是“一个动作同时改变多个空间关系”。传送后的复合体就应该具有这种多层后果，而不是只移动到另一个位置。

### Paquerette Down the Bunburrows

可以借鉴它对于空间预判和递归理解的处理，但不适合照搬兔子捕获机制，否则会让作品的主题变得混乱。

### Railbound

它提供关卡编辑器，说明解谜游戏的内容工具本身就是产品的一部分。我们的 Level Workbench 可以进一步发展成可视化关卡编辑器。

### Handshakes

适合借鉴双实体协同和短关卡设计。未来可以设计一个关卡，让玩家同时管理两个不能合并但必须配合的部件。

### Void Stranger

它展示了网格游戏的深度可以来自隐藏规则和知识层，但这类设计对叙事和长期内容要求很高，不适合当前低风险 Demo 阶段。

## 5. 市场与设计模式总结

### 模式一：一个动词，长期深挖

成功作品通常不会一开始就推出十几个动作。它们先让玩家完全理解一个动作，再通过空间组合制造深度。

我们的主动词应该固定为：

`移动 -> 拆分 -> 传送 -> 重组`

### 模式二：规则可视化优先于教程文本

优秀作品通常通过房间结构、颜色和动画教学，而不是弹窗解释。

我们的关卡应该做到：

- 第一次看到传送门就知道入口和出口
- 第一次看到复合目标就知道需要整体形状
- 第一次看到拆分提示就知道会切断连接

### 模式三：低惩罚是难度放大器

撤销、即时重开和短动作序列能让关卡更难，但不会让玩家烦躁。

### 模式四：关卡编辑和自动验证是长期内容能力

商业解谜游戏的关键不是做出一关，而是稳定制作大量关卡。编辑器、求解器和回放验证比单个花哨机关更重要。

## 6. 我们的差异化机会

市场位置可以定义为：

**物质工程解谜**

玩家不是单纯移动箱子，而是在管理一种可以被拆解、运输、重新连接的可编程物质。

核心卖点：

- 结构可以被主动改变
- 空间位置和物体形状同时变化
- 传送门对多格实体整体生效
- 目标要求完整结构而不是单点占领
- 关卡可以有多个可行结构，但只有一个符合机器约束

这个方向可以避免变成普通 Sokoban 换皮，也不会陷进递归空间、化学模拟或复杂剧情中的高成本路线。

## 7. 对我们 Demo 的具体建议

### 近期必做

- 用不同形状的目标展示“结构要求”
- 增加拆分连接线和重组连接动画
- 在传送门触发时显示整体轮廓，避免玩家误以为每个格子单独传送
- 让每一关的首屏构图统一，入口、操作区、目标区一眼可辨

### 第二阶段

- 增加压力板和闸门，让复合体形状直接影响机关
- 增加材质过滤器，要求拆分后按材质分配
- 增加 3 到 6 个奖励房间，允许玩家用非唯一解法完成

### 暂不加入

- 战斗和敌人
- 计时限制
- 随机地图
- 复杂剧情分支
- 递归嵌套空间
- 大量新动词
