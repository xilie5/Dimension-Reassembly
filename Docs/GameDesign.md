# Compound Box - Game Design

## 1. 产品定位

类型：单机 2D 网格解谜  
目标平台：PC，键鼠  
单局时长：5-8 分钟  
Demo 内容：12 个递进式关卡，包含完整操作、反馈、重试和完成循环

作品集目标不是堆叠内容量，而是展示一个从规则设计、关卡教学、程序架构到自动化验证都闭环的可玩垂直切片。

## 2. 市场参考与借鉴点

### Classic Sokoban

借鉴点：

- 单步移动和可预测推挤
- 棋子少、信息完整、无需教程文本
- 通过空间限制制造解法，而不是通过数值难度

本项目的不同点：

- 物体不限制为单格箱子
- 物体可以被拆分和重组
- 传送门对复合体整体生效

### Baba Is You

借鉴点：

- 规则组合带来的涌现式解法
- 同一套物体在不同语境下承担不同功能

本项目的不同点：

- 不修改规则文本
- 组合变化集中在空间和实体结构层面，降低理解与 UI 成本

### Patrick's Parabox

借鉴点：

- 传送区域作为规则本身，而不是单纯捷径
- 玩家通过空间关系理解“物体如何保持自身”

本项目的不同点：

- 传送对象是可以占多个格子的复合实体
- 传送后保持锚点和相对形状，便于形成稳定的关卡语言

### A Monster's Expedition / Sokobond

借鉴点：

- 低惩罚、快速重试
- 新概念先单独出现，再与其他机制组合
- 用世界中的图形而不是长说明引导玩家

## 3. 设计支柱

### 3.1 一个动作，两层含义

每个操作既要改变位置，也要改变后续可能性。例如拆分不只是把物体变小，还会切断其整体移动能力；重组不只是恢复整体，还会改变一个物体的占地轮廓。

### 3.2 规则必须可读

单位状态、目标、传送门入口和出口都必须有稳定视觉编码。HUD 不承担教学核心，关卡本身负责教学。

### 3.3 低惩罚试错

每关规模小，支持即时撤销和重开。玩家失败后的主要成本是思考，而不是重复劳动。

### 3.4 内容可验证

每个关卡都保存标准解法代码。编辑器和测试使用同一套生产规则回放解法，防止策划数据与运行逻辑脱节。

## 4. 核心规则

### 复合实体

- 一个实体由一个或多个正交格子组成
- 实体移动时所有格子保持相对形状
- 玩家推动实体时，按推箱子规则检查整条推挤链
- 传送门触发时以实体锚点为对齐基准

### 拆分

- 玩家面前必须是复合实体
- 拆分后每个格子成为独立的一格实体
- 拆分保留材质，不保留原实体 ID
- 单格实体不能再次拆分

### 重组

- 所有同材质且正交相邻的实体形成一个组合组
- 一次重组会处理棋盘上的全部有效组合组
- 不同材质即使相邻也不会合并

### 目标

- 普通目标要求指定材质占据该格
- 复合目标要求指定材质，同时物体至少包含两个格子
- 可选出口要求玩家在所有目标满足后到达出口

## 5. 关卡节奏

| 关卡 | 教学重点 | 组合方式 |
| --- | --- | --- |
| First Push | 移动、推挤、目标、出口 | 基础规则 |
| Split Decision | 拆分后分别管理多个物体 | 拆分 + 推挤 |
| Anchor Transit | 单格物体进入传送门 | 传送 + 推挤 |
| Compound Gate | 多格物体验证整体传送 | 传送 + 复合体 |
| Reassembly | 相邻同材质物体重组 | 重组 + 复合目标 |
| Phase Loom | 复合体传送、拆分、双目标配送 | 全机制综合 |
| Dual Alloy | 混合材质整体移动 | 多材质 + 推挤 |
| Alloy Split | 混合材质拆分配送 | 材质 + 拆分 |
| Molecule Socket | 多格材质目标 | 复合目标 + 材质 |
| Precision Cut | 精确切割连接边 | 连接图 + 切割 |
| Rotation Vault | 复合体旋转 | 旋转 + 推挤 |
| Portable Gate | 可移动传送出口 | 动态拓扑 + 综合 |

## 6. 反馈与表现

- 移动使用短促位移和轻微起伏
- 推挤使用更低沉的反馈音
- 传送使用更长的频率扫动音
- 拆分和重组使用方向相反的扫频提示
- 目标满足数量实时显示
- 完成时使用居中完成面板

白盒风格有意保留，以便把评审注意力集中在规则、状态变化和工程结构上。后续可以由美术按现有 Sprite 接口替换表现层，而不需要修改规则层。

## 7. Demo 完成标准

- 新玩家无需阅读文档即可完成第一关
- 12 个关卡均可通过记录的解法完成
- 一次错误操作可以在 1 秒内撤销
- 规则层在不启动场景时可以被自动测试
- 新增关卡只需提供文本布局和可选解法代码
